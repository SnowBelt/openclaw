# Pattern Lab YouTube Public Profile

## About Description

Pattern Lab explains the hidden systems behind American cities.

Hosted by James, each episode uses maps, archives, old photographs, buildings, neighborhoods, infrastructure, industry, and records to understand why a city became what it is.

We start with Detroit, then follow the same evidence-first format city by city. No fake archival photos. No random trivia. No recycled history summaries.

Just the source, the place, and the system behind the story.
